# small-cap-buzz

סורק "באז מתהווה" במניות קטנות: מזהה טיקרים שהשיח עליהם בפורומים מאיץ **לפני** שהמחיר זז, ושולח התראה לטלגרם.

## איך זה עובד
כל 30 דקות בימי מסחר (בערך 04:00-17:00 ET), כל 4 שעות בסופ"ש ופעמיים בלילה:
1. **ApeWisdom**: אזכורים ב-24 שעות ב-all-stocks ובכמה פורומים נפרדים. כל הרצה נשמרת ב-`data/snapshots`, כדי למדוד האצה מול הבסיס של אותה מניה ב-7 הימים האחרונים ומול 3 שעות קודם.
2. **Reddit API** (אופציונלי): פוסטים ותגובות חדשים, ומספר כותבים שונים ופורומים ב-6 השעות האחרונות.
3. **StockTwits**: טרנד, קצב הודעות, וגידול במספר העוקבים ב-24 שעות.
3א. **נפח חריג** (Yahoo, כולל פרה-מרקט), **עמלת השאלה וזמינות לשורט** (iBorrowDesk), **Xueqiu** (מניות אמריקאיות חמות בסין), **YouTube** (אופציונלי), **קידום בתשלום** (stockpromoters – חוסם), ו**סימון חברות מסין/הונג קונג** (SEC).
4. **סינון**: מחיר (Yahoo) – פחות מ-15% מעל הסגירה הקודמת; שווי ופלואט ושורט (Finviz/stockanalysis) – עד $500M; דיווחי הנפקה ב-SEC ב-30 יום (S-1/S-3/F-1/F-3/424B) – חוסמים; ETF ומילים נפוצות מסוננים.
5. **ציון**: האצה, קצב ב-3 שעות, פיזור בין פורומים, כותבים שונים, סטוקטוויטס, שורט ≥20%, פלואט <50M. התראה מציון 6 ומעלה, לכל היותר פעם ב-24 שעות לטיקר.
5א. **סימני הרצת פורומים** (מההיסטוריה של `data/snapshots`): שיח שעולה 3 ימים ברציפות (+1), מניה חדשה בשיח שלא דוברה 14 יום (+1, פעיל אחרי 5 ימי היסטוריה), דיווח טרי ב-SEC מ-3 הימים האחרונים (8-K, 6-K או 13D, +1). רוב האזכורים ברדיט מכותב אחד או שניים (-1).
5ב. **חסימות נוספות**: המניה כבר רצה (+30% ב-3 ימים או +60% ב-10 ימים), שווי מתחת ל-$3M, ואיחוד מניות או שינוי יחס ADS ב-10 הימים האחרונים. לפי Yahoo, לפי 8-K Item 5.03 או לפי חיפוש טקסט ב-SEC ל-6-K. איחוד מניות בין 11 ל-60 יום מוריד נקודה ומוסיף אזהרה.
6. **יומן**: כל התראה נשמרת ב-`data/alerts.json` עם מחיר ההתראה, ובכל הרצה מתעדכנת התוצאה (סגירה אחרונה, מקסימום ב-5 ימים) ממחיר ההתראה.

הספים נמצאים ב-`scanner/config.py`.

## Secrets (Settings → Secrets and variables → Actions)
| שם | חובה | מה |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | להתראות | טוקן מ-@BotFather |
| `TELEGRAM_CHAT_ID` | להתראות | ה-chat id שלך |
| `REDDIT_CLIENT_ID` | לא | אפליקציית script ב-reddit.com/prefs/apps |
| `REDDIT_SECRET` | לא | ה-secret של האפליקציה |
| `REDDIT_USER_AGENT` | לא | למשל `script:small-cap-buzz:0.1 (by u/USERNAME)` |
| `YOUTUBE_API_KEY` | לא | מפתח חינמי מ-Google Cloud (YouTube Data API v3) |
| `SEC_USER_AGENT` | מומלץ | שם ומייל ליצירת קשר, ש-SEC דורש, למשל `Tzachi tzachi@example.com` |

בלי טלגרם, התוצאות מופיעות בסיכום של כל הרצה בלשונית Actions.

## תזמון
GitHub לא מבטיח הרצות מתוזמנות: בעומס הוא מדלג עליהן או מעכב אותן, ולכן הדקות בקובץ ה-workflow אינן עגולות. אם עדיין חסרות הרצות, אפשר להפעיל את ה-workflow מבחוץ, למשל עם cron-job.org שקורא ל-`workflow_dispatch` עם טוקן אישי של GitHub.
